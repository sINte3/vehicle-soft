# Реплей августа-2026 — отчёт о воспроизводимости

Модель `dji-area-evidence-2026-09-08-final-1`, реализация
`dji-area-evidence-2026-09-08-final-1-impl-2` (разделы 1-7 сняты на
impl-1, повтор под impl-2 -- раздел 8). Прогон 2026-09-08,
артефакты — `C:\VehicleSoft_DJI_Area_Implementation_Runs\20260908_103726\replay\`.

**Чем этот отчёт является.** Доказательством того, что реализация
воспроизводит эталонные числа нормативного пакета из САМИХ ИСТОЧНИКОВ, а не
из таблиц исследования. Ни одно эталонное число не зашито в код: totals
вычислены пересчётом и сверены после.

**Чем он не является.** Ни живым сбором (кабинет DJI из сессии не
открывался), ни сентябрьским holdout, ни ручной сверкой владельца, ни
подтверждением физической площади.

Консервативный сценарий вычислен формулой модели
(`RAW − Σ RAW(flat) − Σ (RAW − D)(partial)`) на строках расчёта, а не взят
из документа; совпадение до шестого знака — свойство данных, не подгонка.

**Расхождение по `MISSING_OR_BAD_WINDOW`, названное прямо.** Эталон
объединяет пять записей в один класс «UNKNOWN». Реализация различает их по
причине: три записи без V4 в цепочке возобновления → `UNKNOWN_SUSPECT`
(corrected NULL), одна (`694956303`) дополнительно пересекается по интервалу
с соседней записью того же борта → `OVERLAP_REVIEW` (corrected NULL,
исключена из certified), одна обычная без V4 → `RAW_UNVERIFIED`
(A provisional). Ни одна не получила ноль. Суммарная RAW-экспозиция этих
пяти — 32 072 м², как в эталоне.
