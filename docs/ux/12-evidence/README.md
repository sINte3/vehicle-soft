# Доказательные кадры

Кадры, на которые прямо ссылается `docs/ux/12-problem-register.md`. **Только
они лежат в git** — полная матрица базиса (560 кадров, 108 МБ) остаётся
регенерируемым артефактом, см. `docs/ux/11-baseline/README.md`.

Имя файла начинается с идентификаторов проблем, которые кадр доказывает.

| `PR-043-044-dashboard-card-in-card.png` | PR-043, PR-044 | Главная: 7 модульных карточек, в каждой большое число плюс сетка 2×2 вложенных плиток — 35 чисел, таблица ниже сгиба. В нижнем ряду часть плиток показывает `0`, часть — только подпись без числа |
| `PR-020-ref-equipment-mobile-overflow.png` | PR-020 | `/ref/equipment` при окне 390 px: документ шириной 1170 px, втрое шире экрана |

Условия съёмки, вьюпорты и ограничения — `docs/ux/11-baseline/README.md`.

production не затрагивались.
