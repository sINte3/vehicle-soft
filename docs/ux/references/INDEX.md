## Колонки

- **Паттерн одной фразой** — что наблюдается, а не какой продукт изображён.
- **Реплика владельца** — зачем кадр сохранён, его словами. Ценнее самого
  изображения: называет проблему, ради которой кадр отобран.
- **PROBLEM-ID** — запись `docs/ux/12-problem-register.md`, на которую
  отвечает паттерн. Пусто → в спецификацию не идёт (это ожидаемый и
  нормальный исход для части материала).
- **Вердикт** — ADOPT / ADAPT / INSPIRE / REJECT, проставляется в фазе P2,
  не при раскладке.
