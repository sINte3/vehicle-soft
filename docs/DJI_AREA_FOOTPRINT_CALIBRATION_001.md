# DJI-AREA-FOOTPRINT-CALIBRATION-001 — отделяет ли след распыления фантом от работы

Продолжение DJI-AREA-APPLICATION-MOTION-001. Только чтение: алгоритм, резолвер,
учёт, схема не менялись; миграций, backfill, обращений к DJI, решений
администратора и записей в базу нет. Порог заранее не выбирался. Инструмент —
`tools/dji_area_footprint_calibration.py` (самотест
`tools/test_dji_area_footprint_calibration.py`).

**Ответ: SEPARABLE на данных августа.** У всех 808 доказанных настоящих обработок
с информативным каналом след ≥ 0,50 RAW при самом невыгодном выборе ширины, у
всех 25 записей `APPLICATION_WITH_FLAT_COUNTER` — ≤ 0,28 RAW при самом выгодном.
Пересечения нет. Окончательная проверка — на production (§7), одна команда.

## 1. Что сравнивалось

Реплика августа (`C:\VehicleSoft_DJI_Area_Implementation_Runs\20260908_103726`,
копия в песочнице): 1410 тел V4, 8440 строк расчёта `impl-4`, записанных кодом
`main`. Группы — по текущим строкам расчёта:

| Группа | Что это | Записей | С кадрами применения |
|---|---|---|---|
| A1 | `RAW_CORROBORATED`: полное проверенное окно, прирост счётчика = RAW | 75 | 68 |
| A2 | `RAW_CORROBORATED_QUALIFIED`: прирост закодированного подокна = RAW | 851 | 740 |
| B | REVIEW `APPLICATION_WITH_FLAT_COUNTER` | 25 | 25 |
| C | ручные фантомы 679813767, 693319955, 698068932 (внутри B, только санити) | 3 | 3 |

Все 118 обработок A без кадров применения — один борт `1581F5742255T0C1L061`
(3 Gijduvon, канал `UNRELIABLE`): он не пишет ни флага, ни расхода, и след у
него всегда 0. Поэтому признак применим только при информативном канале — как и
сама группа B, куда запись без применения не попадает. Ниже A = 808 записей с
кадрами применения.

**След** считается только на кадрах применения (флаг ИЛИ расход, не весь
маршрут): шаг `k-1 → k` входит, если в кадре `k-1` шло применение и
0 < dt ≤ 1 с; ширина шага — поле 6 кадра, иначе медиана записи, иначе ширина из
списка. Ширина была у каждой записи (у 4 записей B — только в кадрах без
применения, взята медиана записи), наблюдаемость кадров применения — 100 %,
пропущенных шагов нет ни в одной группе.

Абсолютный след **не** разделяет: у A1 есть работы в один квант (RAW 6 м², след

жидкости на RAW тоже **не** разделяет: у B 698354474 на месте вылито 847 единиц
при RAW 0,072 га (1,18 ед./м²), что выше минимума A1 (0,80).

Верхний хвост A2 — 674435338: 488 м распыления на 40 м² новой площади (след в 77
раз больше RAW). Это прямое наблюдение: счётчик DJI не считает повторное
распыление по уже учтённой земле. Тот же механизм объясняет след B: распыление
было, новой площади — нет, а RAW повторяет площадь предыдущей записи.

## 5. Вывод и самый консервативный кандидат

**SEPARABLE** на августе: след/RAW отделяет записи, чей RAW не подтверждён
собственным распылением, от доказанных настоящих обработок без единого ложного
срабатывания и с запасом ≥ 1,8 раза при худшей ширине.

Самый консервативный кандидат (НЕ реализован, решение владельца):

- домен: плоский счётчик в полном проверенном окне (концы равны по битам),
  RAW > 0, применение есть, канал не из `KNOWN_UNRELIABLE_APPLICATION_HARDWARE`,
  все шаги применения наблюдаемы (0 < dt ≤ 1 с, координаты есть);
- признак: путь при применении × **максимальная ширина парка** / RAW — от ширины
  самой записи не зависит, поэтому пропавшая или нулевая ширина решения не
  меняет;
- граница: не выше **1/10 порога настоящих работ**, установленного на
  production (на августе 0,503 → X ≈ 0,05);
- исход: RAW не подтверждён; что принять — 0 (как решил администратор по трём
  фантомам) или след — бизнес-правило владельца.

На августе такой кандидат отметил бы 22 из 25 (16,06 га из 17,21), включая три
ручных фантома, и оставил бы человеку 687610350, 694249136 и 677423238.
