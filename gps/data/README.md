# Размеченные участки — обучающий набор трека

`labelled_sites.json` — участки, найденные движком по трекам, и ответ владельца
по каждому: работа это или проезд. На август 2026 это **51 участок за 15
машино-дней**, 35 «работа» и 16 «проезд».

Набор лежит в репозитории, потому что это единственный невосстановимый актив
задачи: движок можно написать заново, а разметку — только заново попросить у
человека. До 14.08.2026 она жила во временных файлах сессии.

## Поля

| Поле | Что это |
|---|---|
| `batch` | когда получена разметка |
| `machine`, `day`, `site` | машина, сутки и номер участка внутри суток |
| `label` | ответ человека: `работа` или `проезд` |
| `area_ha` | площадь участка по методу (альфа-форма, адаптивная альфа) |
| `pass_spacing_m` | измеренный шаг между проходами |
| `coverage` | доля участка, покрытая буфером пути |
| `path_density_m_per_ha` | метров пути на гектар |
| `parallelism` | согласованность курсов |
| `points_inside` | сколько точек трека попало внутрь участка |
| `return_share` | доля точек, у которых есть сосед, до которого ехали кругом |
| `hours_per_ha` | время **на участке** на гектар (без провалов длиннее 5 минут) |
| `turns_per_ha` | разворотов больше 120° за минуту, на гектар |
| `speed_cv` | коэффициент вариации скорости |
| `track_available` | доступен ли сырой трек локально: у 10 строк из 51 нет |

Числа считаются `gps/area.py` при `min_area_ha=0.2`. Номер участка внутри
суток зависит от этого порога, поэтому при добавлении новых партий участок
опознаётся по паре «площадь + сутки», а не по одному номеру.

## Что с ним делали

Разбор — `docs/GPS_PLAN_FAKT_VISION_ROADMAP.md` §2.8. Коротко: из восьми
признаков базовый уровень «всё считать работой» превосходит только площадь
(88% против 66%), и её ошибки приходятся на дорогие случаи — крупные проезды.
Поэтому автоматического вердикта нет, решение за оператором, а набор копится.

## Как пополнять

`tools/gps_label_sites.py` строит страницу разметки из треков; ответы
возвращаются текстом вида `машина|дата|#3|1.24 га;работа`. Рядом со страницей
кладётся `gps_label.csv` с признаками — по нему ответы соединяются с числами
без пересчёта.

Набору не хватает **проездов**: их 16, из них крупнее 0,5 га всего 3. Новые
партии имеет смысл набирать по дням с перегонами и поездками, а не только по
дням чистой полевой работы.
