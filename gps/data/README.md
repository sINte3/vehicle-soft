# Размеченные участки — обучающий набор трека

`labelled_sites.json` — участки, найденные движком по трекам, и ответ владельца
по каждому: работа это или проезд. На 15.08.2026 это **66 участков за 18
машино-дней**, 37 «работа» и 29 «проезд».

Две партии. Первая (14.08) размечена по картам и записям экрана, вторая (15.08)
— по странице `tools/gps_label_sites.py`. Из 47 общих участков 45 получили тот
же ответ, 2 — другой; поздний ответ принят, прежний лежит в
`label_first_round`.

Набор лежит в репозитории, потому что это единственный невосстановимый актив
задачи: движок можно написать заново, а разметку — только заново попросить у
человека. До 14.08.2026 она жила во временных файлах сессии.

## Поля

| Поле | Что это |
|---|---|
| `batch` | когда получена разметка |
| `site_id` | опознаватель участка: машина, сутки, номер и площадь |
| `machine`, `day`, `site` | машина, сутки и номер участка внутри суток |
| `label` | ответ человека: `работа` или `проезд` |
| `label_first_round` | ответ первой партии, если участок размечался дважды |
| `area_ha` | площадь участка по методу (альфа-форма, адаптивная альфа) |
| `minutes` | время на участке: сумма промежутков между соседними точками, без провалов длиннее 5 минут |
| `points_inside` | сколько точек трека попало внутрь участка |
| `hours_per_ha` | то же время, делённое на гектары |
| `speed_median` | медианная скорость внутри участка, км/ч |
| `pass_spacing_m` | измеренный шаг между проходами |
| `return_share` | доля точек, у которых есть сосед, до которого ехали кругом |
| `note` | пояснение, если строка чем-то особенная |

Признаки первой партии (`coverage`, `path_density_m_per_ha`, `parallelism`,
`turns_per_ha`, `speed_cv`) в файле не хранятся: ни один из них не превзошёл
базовый уровень, разбор — в §2.8 дорожной карты, а пересчитать их из треков
можно в любой момент.

Числа считаются `gps/area.py` через `tools/gps_label_sites.py` при
`--min-ha 0.15`. Номер участка внутри суток зависит от этого порога, поэтому
участок опознаётся по паре «площадь + сутки», а не по одному номеру — площадь
для того и входит в `site_id`.

## Что с ним делали

Разбор — `docs/GPS_PLAN_FAKT_VISION_ROADMAP.md` §2.8 и §2.8.1. Коротко: по
одному признаку лучший результат даёт время на участке (85% против базовых 55%),
но скачок даёт правило **«площадь ≥ 1,3 га ИЛИ время ≥ 25 минут»** — 92% при
исключении по одному. Правило **предрегистрировано, а не введено**: форма
искалась на этих же данных, поэтому приёмка — на следующей партии, по условиям
из §2.8.1.

## Как пополнять

`tools/gps_label_sites.py` строит страницу разметки из треков; ответы
возвращаются текстом вида `машина|дата|#3|1.24 га;работа`. Рядом со страницей
кладётся `gps_label.csv` с признаками — по нему ответы соединяются с числами
без пересчёта.

Чего набору не хватает теперь: он собран с **18 машино-дней десяти машин**, и
новые примеры нужны прежде всего с ДРУГОЙ техники и других видов работ —
культивация и опрыскивание в нём есть, пахоты, сева и уборки нет. Это требует
новых треков из Wialon.
